# 数据标注作品集：五份短规范 + 视频 / 音频补充计划

适用工具：Label Studio（本地版）  
依据：公开仓库 [data-annotation-portfolio](https://github.com/lixiaoli888/data-annotation-portfolio) 现有导出，以及 2026-11-15 的缺口核对。  
日期：2026-11-18（亚洲/上海）

使用方法：先把对应规范放到该任务目录里，再按「优先补什么」往现有项目里加样本。不要另起一套标签名，除非规范里写明要改。

---

## 1. 情感分类短规范

标签（单选，沿用现有英文）：`Positive` / `Negative` / `Neutral`

| 标签 | 何时使用 |
| --- | --- |
| Positive | 整体在称赞、感谢、推荐，或明确表达满意 |
| Negative | 整体在抱怨、否定、讽刺、厌恶 |
| Neutral | 陈述事实、犹豫、不确定，或褒贬相当、看不出主导态度 |

划界：
- 看整句主导态度，不因为里面有一个好词就标正向。
- 反讽、阴阳怪气按真实态度标。例如现有「这评论区感觉大家赚钱好容易，动不动100w」应标 `Negative`，不能因为字面说「好容易」就标正向。
- 先夸后贬、一句里两种态度：哪种更重标哪种；分不出主导就标 `Neutral`。
- 带否定的句子看否定的对象。「不是不好，就是有点贵」偏中性或主导抱怨价，不标 `Positive`。
- 客观描述里夹着担心，如现有「拿到手冰都化了，不知道坏没坏」：没有明确责骂或下结论时，标 `Neutral`。

优先补：中性和正向；带否定的句子；反讽；先夸后贬；更长的评论（现有大多十几到二十多字）；边界样本。建议补到约 80 条。

疑难请在标注结果里留一句说明，写清为什么这样标。

## 2. 命名实体识别短规范

标签（可多段标注）：`品牌`、`系列名`、`产品名`、`规格`、`材质`

说明：现有导出只有前四类里的「品牌、产品名、规格、材质」。系列名（星飞帆、铂金装、白金版、一级帮、星蕴）目前大多漏标。补样本前在 Label Studio 里加上 `系列名`，不要把系列名并进产品名或品牌里。

| 标签 | 标什么 | 不标什么 |
| --- | --- | --- |
| 品牌 | 厂家或主品牌，如 贝亲、好奇、飞鹤、爱他美 | 系列、子品牌、普通名词 |
| 系列名 | 品牌下的系列或子品牌，如 星飞帆、铂金装、白金版、一级帮、星蕴 | 单独的产品通称（纸尿裤、奶瓶） |
| 产品名 | 商品通称或品类，如 奶瓶、纸尿裤、调奶器、安全座椅 | 系列名；不要把「有机奶粉」里的「有机」标进产品名，除非它是品名的一部分且无法切开。现有「有机奶粉」可整段标为产品名 |
| 规格 | 段数、克重、尺码、容量、型号，如 2段、900g、NB码、160ml、S号 | 功能卖点（防胀气、可折叠） |
| 材质 | 明确写出的材料，如 玻璃、软硅胶、食品级硅胶 | 手感词（超薄、云感） |

切分约定：
- 品牌、系列名、产品名分开标。例如「飞鹤星飞帆3段」→ 飞鹤`品牌`，星飞帆`系列名`，奶粉`产品名`（若句中出现），3段`规格`。现有「飞鹤星蕴2段」漏了系列名和产品名，补标时按此切开。
- 规格能拆就拆：「2段900g」标成两段（2段、900g），不要再合成一个实体。
- 一句里两个品牌或产品对比，两边都要标。
- 没有实体或只有一个实体的句子也要保留，不要为了凑数只收录「品牌+产品+规格」短句。
- 拿不准是系列名还是产品名时：它不能单独售卖、必须跟在品牌后面，优先标 `系列名`，并在疑难说明里写一句。

优先补：材质；系列名切分；对比句；较长评论中间出现的实体；无实体或单实体句。建议补到约 80 条。

## 3. 客户意图短规范

标签（改为可多选）：`咨询规格/功能`、`对比推荐`、`活动/库存查询`、`投诉/质量问题`、`换货/退货`、`使用反馈`

项目设置：现有控件名还叫 `sentiment`，补样本前改成 `intent`，并改成多选。一条可以同时有两个意图。

| 标签 | 何时使用 |
| --- | --- |
| 咨询规格/功能 | 问容量、尺码、适用年龄、功能、能不能长期用 |
| 对比推荐 | 在两个或以上选项里问更适合谁、选哪个 |
| 活动/库存查询 | 问活动、价格优惠、有没有货、何时补货 |
| 投诉/质量问题 | 指出质量、故障、体验差，要求解释或处理 |
| 换货/退货 | 明确提到换货、退货、退款 |
| 使用反馈 | 描述实际使用感受，尚未明确投诉或要求退换 |

划界：
- 投诉里顺便问「怎么处理」「能退货吗」，两个都标。例如现有「奶嘴用了几天就裂了，质量有问题，怎么处理？」应标 `投诉/质量问题` + `换货/退货`（问如何处理，视为退换诉求）。「调奶器温度不准……能退货吗？」同样两个都标，不要只留投诉。
- 「喝了老是吐奶，是不是不适合？」以使用体验为主、没有要求处理时，标 `使用反馈`；若同时质问质量并要求解决，再加 `投诉/质量问题`。
- 对比 vs 规格咨询：出现「A 和 B 哪个更适合」标 `对比推荐`；只问单一产品「有没有更大容量」标 `咨询规格/功能`。
- 多意图时不必强行只留一个「主意图」。如需记录主意图，写在该条的注释里。

优先补：换货/退货、使用反馈；投诉+退货、咨询+对比等组合；易混句。建议补到约 80 条。

## 4. 方面情感短规范

方面：`产品`、`物流`、`客服`  
极性：`正`、`负`、`中`  
规则：一句里每提到一个方面，都要单独给出极性和说明，不能把多个方面揉成一条。

项目设置：现有导出是一次勾选「方面 + 极性」，所以「奶瓶质量很好，就是物流太慢了」只留下了物流负，漏了产品正。补样本前改成三个方面各有一档极性，选项为：`正` / `负` / `中` / `未提及`。只给实际提到的方面打极性。

| 方面 | 包括 | 注意 |
| --- | --- | --- |
| 产品 | 质量、口感、吸收、价格、好不好用、适不适合 | 「包装破损」若明显是运输包装，归 `物流`；若是产品销售包装本身的设计或出厂破损，归 `产品`，拿不准时标物流并写疑难说明 |
| 物流 | 发货速度、快递、运输、外包装在运输中的破损 | 「发货快」是物流正，不是产品正 |
| 客服 | 回复态度、建议、处理方式 | 客服建议换段、态度还行，标客服 `中` 或 `正`，不要用客服结果代替产品极性 |

同一方面里又褒又贬（「材质柔软，就是容易裂，质量一般」）标 `中`，不要只取一半。

按此回看现有 8 条，至少应补标：
- 「贝亲奶瓶质量很好，就是物流太慢了」→ 产品正 + 物流负
- 「拉拉裤本身挺好用，但包装有点破损」→ 产品正 + 物流负
- 「奶粉喝了胀气，客服建议换段，态度还行」→ 产品负 + 客服中

优先补：多方面且极性不同的句子；客服的明确正/负；极性清楚的单方面句。建议补到约 80 条。

## 5. 目标检测短规范

标签（沿用现有，统一小写）：`people`、`car`、`cat`、`dog`

项目设置：现有导出里几乎是街景人车，且汽车标签写成了 `Car`。补样本前把类别名统一成全小写。README 写了 cat、dog，但导出里一个框都没有，这两类必须补上。

画框约定：
- 可见目标都要框，包括被遮挡、位于画面边缘被截断的。框贴合可见部分，不要为了「补全想象中的身体」把框拉到画面外很远。
- 严重遮挡：还能明确判断类别就标；完全看不清就不标。
- 最小目标：人能辨认出身形或车辆轮廓就标；只是几个像素的影子不标。
- `car` 包括轿车、SUV、面包车、公交、货车；不包括自行车、摩托车（这两种本任务不标，不要临时加类）。
- 人和宠物叠在一起时，人、猫/狗分开框，不要画成一个大框。
- 不要漏标远距离小目标；也不要为不在标签里的物体临时发明新类。

优先补：猫和狗、人与宠物重叠、严重遮挡、边缘截断、夜间或逆光、室内、近景大目标。建议补到约 50–80 张图。

## 6. 视频、音频标注集怎么做、怎么上传

先加两个新任务，不要一上来再叠目标跟踪。每个任务先做 20 条能交得出去的样本，再补到 40–50 条。媒体以自己录的为主，短、小、能讲清规范。

### 6.1 视频：时间轴事件

目录：`数据标注作品集/视频_时间轴事件/`  
工具：Label Studio 视频时间轴（给片段打起止时间 + 标签）  
片段：5–15 秒，横竖均可，建议 720p 的 MP4（H.264）

标签（一段视频可有多段事件，按时间切开）：
- `开箱`：拆快递、打开包装
- `口播讲解`：对着镜头说明用法、成分、注意事项
- `产品特写`：只拍商品或细节
- `使用演示`：实际使用过程
- `其他`：转场、路过、对不上上面四类的（少用，用了要写说明）

约定：事件从动作或口播真正开始标到结束；两段紧挨着就在交接处切开，不要重叠太长；看不清就不硬标。不要用整部影视剧或别人的完整带货成片。

可自录开箱、使用演示；服装质检或护肤练习里自己拍的短镜头也可以，但不要放入公司在制品、客户资料或未公开的检测内容。

### 6.2 音频：转写 + 情感

目录：`数据标注作品集/音频_转写与情感/`  
工具：Label Studio 音频 + 转写 + 分类  
片段：5–15 秒，单声道或立体声均可，建议 AAC 的 M4A，或从视频里抽出的音轨

每条要完成两步：
1. 转写：写成实际听到的口播或对话，保留口语，不擅自改得更通顺；听不清标 `[听不清]`，不要猜。
2. 情感：沿用文本情感的 `Positive` / `Negative` / `Neutral`，规范与第 1 份相同。

素材用自己读的评价、自己录的说明，或经对方同意的短对话。不要切别人的播客、影视或带版权音乐当练习集上传。

### 6.3 以后可以再加、现在先不做

视频目标跟踪（把 `people` / `car` / `cat` / `dog` 做到视频上）能和图像检测衔接，但更耗时。等时间轴事件有 20 条稳定样本后，再单独立项。

### 6.4 上传到 GitHub 的方式

公开仓库单文件不超过 100MB，视频很容易超。上传规则：

- 传：该任务的短规范、Label Studio 导出 JSON、少量压缩后的示例媒体（每个建议不超过 8–10MB，一个任务先放 5–8 个示例即可）。
- 不传：原始长视频、未压缩的录音、整段影视或带货成片。
- 完整媒体留在电脑本地，在该任务规范里写一句「完整媒体仅本地保存，仓库只放示例」。
- 建议目录：

```
数据标注作品集/
  文本/
  图像_目标检测/
  视频_时间轴事件/
    规范.md
    导出/
    示例/
  音频_转写与情感/
    规范.md
    导出/
    示例/
```

版权和隐私：不要上传能辨认出路人、儿童正脸的原片；必须用到时先裁切或遮挡。不要把工作中的在制品、客户信息放进公开仓库。

## 7. 建议的进行顺序

1. 在 Label Studio 里按上面的「项目设置」改意图、方面情感、NER、目标检测的标签，再按缺口补现有五个任务。
2. 同时开始自录视频和音频短片段，先各做 20 条，导出 JSON，连同规范和少量示例准备上传。
3. 五份规范和两个新任务都齐了之后，再更新仓库 README，并视情况发布作品集网站、再谈简历表述。
