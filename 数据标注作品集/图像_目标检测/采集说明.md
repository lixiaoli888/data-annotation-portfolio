# 图像目标检测：采集说明

标签统一小写：`people`、`car`、`cat`、`dog`。配置见 `项目配置/目标检测.xml`。

现有导出几乎都是街景人车，没有猫和狗。请自己拍或使用你已有、且可以公开的照片，优先补：

- 猫、狗（必须有）
- 人和宠物叠在一起
- 严重遮挡、画面边缘被截断
- 夜间、逆光、室内
- 近景大目标

注意：

- 不要把路人、儿童正脸大特写直接上传到公开仓库；必须用时先裁切或遮挡。
- 不要从不明来源批量下载图片，以免版权和隐私问题。
- 先拍到大约 20 张新图就可以开始标，目标是总共约 50–80 张。
- 完整原图可留在本地，仓库稍后只放导出 JSON 和少量示例图。
