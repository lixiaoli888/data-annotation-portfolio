# 情感分类短规范

标签（单选，沿用现有英文）：`Positive` / `Negative` / `Neutral`

| 标签 | 何时使用 |
| --- | --- |
| Positive | 整体在称赞、感谢、推荐，或明确表达满意 |
| Negative | 整体在抱怨、否定、讽刺、厌恶 |
| Neutral | 陈述事实、犹豫、不确定，或褒贬相当、看不出主导态度 |

划界：
- 看整句主导态度，不因为里面有一个好词就标正向。
- 反讽、阴阳怪气按真实态度标。例如现有「这评论区感觉大家赚钱好容易，动不动100w」应标 `Negative`，不能因为字面说「好容易」就标正向。
- 先夸后贬、一句里两种态度：哪种更重标哪种；分不出主导就标 `Neutral`。
- 带否定的句子看否定的对象。「不是不好，就是有点贵」偏中性或主导抱怨价，不标 `Positive`。
- 客观描述里夹着担心，如现有「拿到手冰都化了，不知道坏没坏」：没有明确责骂或下结论时，标 `Neutral`。

优先补：中性和正向；带否定的句子；反讽；先夸后贬；更长的评论（现有大多十几到二十多字）；边界样本。建议补到约 80 条。

疑难请在标注结果里留一句说明，写清为什么这样标。
