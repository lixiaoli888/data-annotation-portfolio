# 开始标注（从这一份做起）

作品集里的标注要由你本人完成。下面已经为你准备好规范、Label Studio 项目配置，以及四份待标注文本。按顺序做即可。

建议顺序：先做情感分类（最熟、改动最小）→ 命名实体识别（新加「系列名」）→ 客户意图（改成多选）→ 方面情感（三个方面分开打极性）→ 再利用周末自录图片、视频和音频。

## 1. 在 Label Studio 里更新或新建项目

1. 打开本地 Label Studio，进入对应项目。
2. 打开 Settings → Labeling Interface，把仓库里该任务的 XML 配置整段粘贴进去并保存。
   - 情感分类：`数据标注作品集/文本/项目配置/情感分类.xml`
   - 命名实体识别：`数据标注作品集/文本/项目配置/命名实体识别.xml`（已加入「系列名」）
   - 客户意图：`数据标注作品集/文本/项目配置/客户意图.xml`（控件名改为 intent，可多选）
   - 方面情感：`数据标注作品集/文本/项目配置/方面情感.xml`（产品 / 物流 / 客服各打一档极性）
3. 意图和方面情感的旧项目如果已经有标注，先导出备份，再改配置，避免旧结果对不上新字段。
4. 四个文本任务也可以各建一个新项目，把旧导出留作对照。

## 2. 导入待标注文本

文件在 `数据标注作品集/文本/待标注/`：

- `情感分类.json`（37 条）
- `命名实体识别.json`（35 条）
- `客户意图.json`（35 条）
- `方面情感.json`（35 条）

在项目里选择 Import，上传对应 JSON。这些句子是为练习新写的，不是你的旧样本，里面没有现成答案，请按该任务规范自己标。

导入后先标 5 条，对照规范看一眼有没有卡壳，再往下做。遇到拿不准的，用配置里的「疑难说明」写一句。

## 3. 标完后导出并放回作品集

1. 在 Label Studio 里 Export，格式选 JSON。
2. 把导出文件放到该任务目录（例如 `数据标注作品集/文本/`），不要覆盖旧导出，新文件用新文件名。
3. 需要的话告诉我，我帮你检查格式、漏标和边界样本，再一起更新仓库和 README。

## 4. 图像、视频、音频先采集，再导入

这三类先不要找影视剧或别人的完整带货视频。按各目录里的 `采集说明.md` 自己拍、自己录：

- 图像：补猫、狗，以及遮挡、截断、夜间或室内；标签统一小写 `people` / `car` / `cat` / `dog`
- 视频：5–15 秒短片，标时间轴事件（开箱、口播讲解、产品特写、使用演示）
- 音频：5–15 秒，先转写再标情感

采集后用对应 XML 新建项目，把媒体导入再标。完整原片留在电脑里，仓库以后只放导出 JSON 和少量压缩示例。
