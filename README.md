# 数据标注作品集

## 项目简介
本作品集记录了从零基础学习数据标注的实践过程，涵盖图像与文本两类模态，目标是掌握常见标注任务并具备基础质检意识。

## 已完成内容

### 1. 图像标注 - 目标检测（Bounding Box）
- 工具：Label Studio（本地版）
- 任务类型：矩形框标注
- 标签：people、cat、car、dog 等
- 练习重点：遮挡目标处理、远距离小目标漏标控制、框贴合度
- 文件位置：`图像_目标检测/`

### 2. 文本标注
- 工具：Label Studio
- 已完成任务类型：
  - 情感分类（Positive / Negative / Neutral）
  - 命名实体识别（品牌、产品、规格等）
  - 客户意图标注（咨询、投诉、对比推荐、换货等）
  - 方面情感标注（产品/物流/客服 + 正负中）
- 文件位置：`文本/`

### 3. 基础数据清洗
- 练习内容：去重、多余标点修正、空格清理
- 目的：理解常见脏数据问题及处理原则

## 学习收获
- 熟悉 Label Studio 从建项目到导出 JSON 的完整流程
- 建立了漏标、误标、边界案例的质量意识
- 能独立完成图像画框与多种文本标注任务
