## 已完成内容

### 1. 图像标注 - 目标检测（Bounding Box）
- 工具：Label Studio（本地版）
- 任务类型：矩形框标注
- 标签：people、cat、car、dog 等
- 当前练习量：两份已有导出共 11 张图，框出的类别是 people 和 Car
- 练习重点：遮挡目标处理、远距离小目标漏标控制、框贴合度
- 文件位置：`图像_目标检测/`

### 2. 文本标注
- 工具：Label Studio
- 已完成任务类型（条数为仓库里已有导出，不含待标注样本）：
  - 情感分类（Positive / Negative / Neutral）：10 条
  - 命名实体识别（品牌、产品、规格等）：19 条
  - 客户意图标注（咨询、投诉、对比推荐、换货等）：10 条
  - 方面情感标注（产品/物流/客服 + 正负中）：8 条
- 文件位置：`文本/`

### 3. 基础数据清洗
- 练习内容：去重、多余标点修正、空格清理
- 目的：理解常见脏数据问题及处理原则
